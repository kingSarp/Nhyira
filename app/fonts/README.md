# Fonts

Self-hosted Latin subsets from [Fontsource](https://fontsource.org), all under the SIL Open Font License 1.1:

- Cormorant Garamond — The Cormorant Project Authors
- Great Vibes — Robert Leuschke
- Source Serif 4 — Adobe

Loaded in `lib/fonts.ts`. Don't add weights without adding them to `docs/design/tokens.json`.
